# User work protection

- Protect the user's work. Never delete, overwrite, reset, restore, or roll back user files, including untracked files, based on assumptions.
- For rollback requests, inspect the exact changes and undo only changes Codex made; preserve the user's existing work and 3D battle/diorama files.
- If ownership or scope is unclear, stop and ask the user.
- Before committing, show the exact staged changes and get the user's confirmation.
- Verify any rollback before claiming it is complete.
