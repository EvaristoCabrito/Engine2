# Hex ground 001

Ten new terrain variants generated with the built-in ImageGen tool. The original assets, FX and saved maps remain available. Select each new variant in the map editor as `Solo contínuo 001`; City is under the City brush.

Nine ground materials share board-aligned mirrored repeats, clipped by the existing pointy-top hex geometry. Mirroring aligns repeat boundaries without editing artwork. Rotation is ignored for these continuous variants. Coluna remains a centered per-cell object and supports existing rotation.

The following common prompt was concatenated directly with each subject below:

Use case: stylized-concept. Asset type: high quality game terrain texture for Ember dark medieval tactical hex board. Create ONE square opaque 1024x1024 full-bleed ground material, strict orthographic camera looking vertically down, realistic hand-crafted PBR-like painted detail, readable at small size. Consistent natural soft diffuse overhead light, subdued earthy palette, no vignette and no center spotlight. Surface must extend to every edge, absolutely no hex silhouette, no transparent margin, no frame, no outline, no bevel, no tabletop diorama, no labels or text. Seamless repeating material: matching opposite edges, uniform edge color and detail density, avoid large features intersecting edges. Texture will be clipped to pointy-top regular hexes by engine; all six hex boundaries must feel like continuous ground, no dark seams or baked shadows at tile boundary. Small feature scale, avoid directional gradients. Subject:
